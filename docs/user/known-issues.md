# 已知问题

按使用中遇到的现象排列。功能范围见[项目状态](../status.md)。

## 首次分区

引导助手提供创建独立分区的入口，但新平板首次分区尚未完成实机验证。
已有独立分区时可直接选择 ESP 和 root 镜像进行安装，无需重新分区。

## 切换刷新率、关屏或合盖后黑屏

当前内核已修复双路显示时钟恢复和关闭顺序，30／48／50／60／120 Hz 使用无缝切换。90／144 Hz 仍会完整重设显示，144 Hz 可能花屏；出现异常时使用桌面的自动回退，不能恢复则重启。建议日常保持默认 120 Hz。细节见[显示恢复](../devel/piano-display-resume.md)。

当前合盖和短按电源会锁屏并关闭显示链路，开盖或再次短按恢复画面。默认 2 分钟空闲后锁屏熄屏，电池供电 5 分钟、外接电源 10 分钟自动挂起。见[显示](../devel/piano-display-depth.md)和[电源键](../devel/piano-power-button.md)。

## UEFI 菜单与 USB

UEFI 菜单白屏已修复，SimpleInit 和 TianoCore 设置页面可以显示。设置页面的字号和输入仍在改善；合体 BOOT 冷启动进入 UEFI 时，USB 调试接口仍可能无法连接。

如果电脑能识别 UEFI 设备，可以查询固件：

```sh
fastboot -s SunUEFI-piano getvar product
```

返回 `piano-sunuefi` 就说明固件正常。可以 `oem boot-stable` 启动 Linux，或 `reboot` 回 Android，见[UEFI Fastboot](fastboot.md)。电脑看不到设备时见[返回 Android](recovery.md)。

## 相机

前后摄像头可以预览和录像。曝光、对焦和首帧处理仍在改善，画质与原厂相机有差距。相机目前没有完整专业模式的应用入口。

## 麦克风

已使用原生单声道录音，旧的空声道混合造成音量衰减的问题已修正。底噪和桌面输入电平仍需调校。

## 电源和睡眠

* 锁屏、熄屏恢复和挂起可用；待机耗电仍需优化，休眠未启用。
* 关机偶尔会回到 Android，原因未知。
* 双电池、基础 PD 充电可用；高压快充和完整充电周期没有验证。

## 启动较慢

当前 Linux 内核和系统服务启动约 39 秒，不含开机选择器与 UEFI，首次启动可能更久。启动过程中可能灰屏或白屏，缺少清楚的进度提示。仅凭屏幕颜色无法区分正在启动与已经停住；不要连续强制重启。系统直接使用内部 ext4 分区，硬件初始化和服务等待仍需优化。详见[启动时间](../devel/piano-boot-time.md)。

## 蓝牙

Linux 启动时自动读取本机原厂蓝牙地址，手工刷写通用镜像也不需要单独填写地址。触控笔在默认 120 Hz 下支持定位、压感、轻捏和震动；其他限制见[笔协议](../devel/piano-pen-protocol.md)。

## 指纹、HDR、Windows

这些功能没有完成，见首页的[尚未完成](../../README.md#尚未完成)。

## 其他

* 新装系统需要自己通过 NetworkManager 保存 Wi-Fi。
* Recovery 里的独立 SunUEFI 镜像已放弃，见[返回 Android](recovery.md)。
* 当前运行使用 CSOT 面板配置，其他面板版本和不同内存容量的平板没有测试过。

## 手写笔与默认刷新率

默认使用 120 Hz，面板自动选择 BOE／CSOT。低刷新率切换保持触控固件运行；144 Hz 笔输入仍需适配。跨 Android／Linux 切换后，磁吸识别与自动配对恢复已接入，首次连接仍可能需要等待几秒。
